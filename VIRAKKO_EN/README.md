# 🚀 VIRAKKO - Content Creation Automation Skill

![VIRAKKO Logo](https://img.shields.io/badge/VIRAKKO-v1.0.0-purple)
![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

**VIRAKKO** is a revolutionary skill that completely automates the video content creation process, from idea generation to final video production.

## ✨ Key Features

- 🎯 **Command activation**: Type "VIRAKKO" + your content to start
- 🤖 **Idea generation**: 3 creative ideas generated by AI (Google Gemini)
- 📜 **Script creation**: Complete scripts with 8-second scenes
- 🎙️ **Voice synthesis**: Professional audio generated with ElevenLabs
- 🖼️ **Image generation**: Initial and final images for each scene
- 🎬 **Video production**: Complete videos using Google FLOW
- 🌐 **Local web**: Web interface to visualize the entire project
- 🌍 **Multi-language**: Spanish, English, Japanese, Chinese

## 🎥 Workflow

1. **Activation**: Type "VIRAKKO <your content>"
2. **Ideas**: 3 script ideas are generated
3. **Selection**: Choose the idea you like best
4. **Script**: A script is created with 8-second scenes (Uruguayan Spanish)
5. **Audio**: Voice is generated for each scene
6. **Images**: Initial and final images are created
7. **Video**: The final video is produced
8. **Web**: A local web page is generated with all content

## 📦 Installation

### Prerequisites

- Python 3.8 or higher
- Chrome Browser (for Selenium)
- ElevenLabs API Key
- Google Gemini API Key (optional)

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configuration

1. Copy the configuration template:
```bash
cp config/settings.json.template config/credentials.json
```

2. Edit `config/credentials.json` and add your API keys:
```json
{
  "elevenlabs": {
    "api_key": "YOUR_ELEVENLABS_API_KEY"
  },
  "gemini": {
    "api_key": "YOUR_GEMINI_API_KEY"
  }
}
```

## 🚀 Usage

### Run the Skill

```bash
python src/main.py
```

